# Test Markdown File with Various Formats

This file tests various markdown checkbox formats to ensure the parser is robust.

## Standard format
- [ ] Standard unchecked
- [x] Standard checked

## No space after dash
-[ ] No space after dash unchecked
-[x] No space after dash checked

## Extra spaces in checkbox
- [ x] Extra space before x
- [x ] Extra space after x
- [ x ] Extra spaces around x

## Different bullet markers
* [ ] Asterisk unchecked
* [x] Asterisk checked
+ [ ] Plus unchecked
+ [x] Plus checked

## Uppercase X
- [X] Uppercase X checked

## Actual exercises with various formats
- [ ] Test Blatt - 1
- [x] Test Blatt - 2
-[x] Test Blatt - 3
* [ ] Test Blatt - 4
+ [X] Test Blatt - 5
